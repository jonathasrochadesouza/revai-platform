How it works

  1. Resolve — paste a GitHub/GitLab URL (tree, pull/482, merge-requests/12, @sha) or pick a local folder.
  2. Clone & diff — the repo is cloned into ~/.revai/repos and diffed against the base (origin/HEAD + merge-base).
  3. Review — your agent harness receives the patch scope and project rules via stdin and writes findings into the clone.
  4. Validate — findings must pass the review schema; failures show the real error instead of a fake report.
  5. Report & fix — triage findings, send blockers to the fix loop, commit only when you say so.

FAQ

What is Revai Platform?

A free, open-source (MIT) desktop app that hosts AI-powered code review locally: it orchestrates the revai review skill end to end and renders the result with a Quality Gate, findings triage and a fix loop.

How is it different from cloud code review tools?

Cloud SaaS reviewers ingest your code into their platform and run models you don't control. Revai Platform inverts that: the review runs on your machine, with the AI agent CLI you already use and pay for, against its own provider — the platform adds orchestration, UI and gate, not a middleman server.

Is my source code uploaded anywhere?

No. Clones live in ~/.revai, the app ships with no telemetry and talks to no backend of its own. The only network calls in a review are the ones your chosen harness CLI makes to its own LLM provider.

Which AI agents can run the review?

Kiro CLI, Claude Code, Codex CLI, OpenCode and GitHub Copilot CLI today; each is discovered and validated at onboarding, with per-harness model selection in Settings.

How much does it cost?

The app is free (MIT license). You only cover the usage of your own agent harness/LLM account.
